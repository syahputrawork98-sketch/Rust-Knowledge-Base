# RAK-03-evolution (History & Future)

> **"Menavigasi Perubahan Antar Generasi (Editions) dan Masa Depan Rust."**

Rust terus berkembang tanpa memecahkan kompatibilitas (Stability without Stagnation). Rak ini membedah bagaimana perubahan terjadi antar Editions.

## Fokus Pembelajaran
1. **Rust Editions**: Perbedaan mendalam antara 2015, 2018, dan 2021.
2. **RFC Process**: Bagaimana fitur baru diusulkan dan diimplementasikan.
3. **Future Prospects**: Rencana pengembangan di tahun-tahun mendatang.
