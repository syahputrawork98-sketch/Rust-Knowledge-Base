# BK-01_Scalar_Types

> **"Atom Dasar Pembentuk Data."**

Tipe Scalar merepresentasikan sebuah nilai tunggal. Rust memiliki empat tipe scalar utama: integer, floating-point, boolean, dan karakter.

## Daftar Isi
1. **CH-01_Integer_Types**: Bilangan bulat, bit-size, dan overflow.
2. **CH-02_Floating_Point_Types**: Bilangan desimal f32 dan f64.
3. **CH-03_Numeric_Operations**: Matematika dasar di Rust.
4. **CH-04_Boolean_Type**: Logika benar dan salah.
5. **CH-05_Character_Type**: Kekuatan Unicode dalam satu karakter.
