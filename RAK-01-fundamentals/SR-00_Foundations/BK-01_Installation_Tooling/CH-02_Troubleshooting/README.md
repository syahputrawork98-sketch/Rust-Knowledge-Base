# CH-02_Troubleshooting

Solusi untuk kendala yang mungkin terjadi selama atau setelah instalasi Rust.

## Deskripsi
Beberapa sistem mungkin mengalami masalah dengan linker atau path. Bab ini merangkum solusi paling umum agar Anda tidak tertahan di tahap awal.

## Topik Utama
- Masalah Linker (C Toolchain).
- Memverifikasi instalasi (`rustc --version`).
- Mengatasi PATH yang tidak terdaftar otomatis.
