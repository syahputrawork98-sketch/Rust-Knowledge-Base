# CH-03_Updates_Uninstall

Menjaga toolchain Rust Anda tetap mutakhir.

## Deskripsi
Rust memiliki siklus rilis yang cepat (setiap 6 minggu). Bab ini menunjukkan cara mengelola pembaruan agar Anda selalu mendapatkan fitur terbaru.

## Topik Utama
- `rustup update`: Memperbarui compiler.
- `rustup self uninstall`: Menghapus Rust secara bersih.
- Manajemen komponen (misal: `rust-src`, `clippy`).
