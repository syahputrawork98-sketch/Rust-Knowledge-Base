# CH-05_IDE_Tooling

Membangun workstation Rust yang premium dengan VS Code.

## Deskripsi
Coding Rust tanpa IDE yang tepat seperti berlari di kegelapan. Bab ini fokus pada setup `rust-analyzer` untuk mendapatkan fitur *auto-complete* dan *error highlighting* secara real-time.

## Topik Utama
- Instalasi VS Code.
- Ekstensi Berwajib: `rust-analyzer`.
- Formatting otomatis (`rustfmt`).
- Linting cerdas dengan `clippy`.
