# CH-04_Local_Documentation

Akses cepat ke dokumentasi teknis tanpa koneksi internet.

## Deskripsi
Rust menyertakan salinan dokumentasi lokal saat instalasi. Ini memudahkan Anda belajar kapan saja dan di mana saja.

## Topik Utama
- Perintah `rustup doc`.
- Struktur dokumentasi offline.
- Referensi API pustaka standar.
