# BK-02_Borrowing_Slices

> **"Menggunakan Tanpa Memiliki: Seni Berbagi Aset."**

Buku ini membahas bagaimana Rust memungkinkan kita untuk membaca atau mengubah data tanpa harus mengambil alih kepemilikannya (*Ownership*). Ini adalah solusi untuk pola "Titip-Balik" yang melelahkan di buku sebelumnya.

## Daftar Isi
1. **CH-01_References_Borrowing**: Konsep Peminjaman Read-Only (Analogi Perpustakaan).
2. **CH-02_Mutable_References**: Aturan main Peminjaman yang bisa mengubah data.
3. **CH-03_Dangling_References**: Bagaimana Rust mencegah referensi ke memori yang sudah mati.
4. **CH-04_String_Slices**: Mengambil potongan teks tanpa menduplikasi data.
5. **CH-05_Other_Slices**: Slices pada Array dan koleksi lainnya.
