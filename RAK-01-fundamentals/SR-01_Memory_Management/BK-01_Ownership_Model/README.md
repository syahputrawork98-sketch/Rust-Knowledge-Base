# BK-01_Ownership_Model

Buku ini membedah konsep **Ownership**, aturan main Rust yang membuat bahasa ini begitu aman namun sangat efisien.

## Daftar Isi
1. **CH-01_The_Concept**: Mengapa Ownership itu ada? (Analogi Pemegang Saham).
2. **CH-02_Ownership_Rules**: Tiga aturan sakti yang tak boleh dilanggar.
3. **CH-03_The_Move_Mechanics**: Perpindahan kepemilikan dan dampaknya pada memori.
4. **CH-04_Copy_Types**: Pengecualian untuk data sederhana (Stack vs Heap).
5. **CH-05_Functions_Ownership**: Bagaimana data berpindah saat masuk dan keluar fungsi.
