# BK-02_Repetition_with_Loops

> **"Kekuatan Pengulangan yang Efisien."**

Mengotomatiskan tugas yang berulang menggunakan tiga jenis loop di Rust. Dari perulangan tak terbatas hingga iterasi koleksi yang aman.

## Daftar Isi
1. **CH-01_Loop_Keyword**: Perulangan murni dan kontrol `break`/`continue`.
2. **CH-02_While_Loops**: Berjalan selama kondisi masih benar.
3. **CH-03_For_Loops**: Cara berkelas untuk mengelilingi data.
