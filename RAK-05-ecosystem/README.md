# RAK-05-ecosystem (The Environment)

> **"Menguasai Ekosistem, Toolchain, dan Standar Paket Rust."**

Rust bukan sekadar bahasa, tapi sebuah ekosistem yang kohesif. Rak ini membedah bagaimana kita berinteraksi dengan dunia luar melalui Cargo dan Standard Library.

## Fokus Pembelajaran
1. **Cargo Professional**: Dependency management, workspaces, dan publishing.
2. **`std` vs `core`**: Memahami `no_std` untuk lingkungan sistem terbatas.
3. **Crates.io**: Menjelajahi standar industri dan community libraries.
