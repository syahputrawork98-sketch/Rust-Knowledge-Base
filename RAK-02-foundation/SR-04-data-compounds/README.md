# SR-04-data-compounds (The Blueprint)

> **"Abstraksi Data dengan Enums dan Pattern Matching."**

Sub-Rak ini memperkenalkan fitur-fitur yang membuat Rust sangat ekspresif dalam menangani berbagai variasi data melalui ADTs (*Algebraic Data Types*).

## 📚 Rencana Pengembangan (Books & Chapters)

### BK-01_Enums_Option
Mendefinisikan tipe data dengan variasi.
- **CH-01_Enum_Basics**: Struktur Enum sederhana vs Enum dengan data.
- **CH-02_Option_Enum**: Solusi Rust untuk ketiadaan nilai `null`.

### BK-02_Pattern_Matching
Mekanika pengambilan keputusan berdasarkan struktur data.
- **CH-01_Match_Operator**: Penggunaan `match` untuk kontrol alur tingkat tinggi.
- **CH-02_If_Let**: Sintaks gula untuk menangani satu variasi pola saja.
