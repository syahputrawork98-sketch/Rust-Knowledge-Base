# SR-02-syntax-basics (Memory Anchors)

> **"Memahami Bagaimana Rust Menyimpan dan Mengelola Data Dasar."**

Sub-Rak ini membedah elemen terkecil dalam Rust: variabel dan tipe data. Fokus pada bagaimana immutability menjadi default dan bagaimana tipe data primitif bekerja di memori.

## 📚 Rencana Pengembangan (Books & Chapters)

### BK-01_Variables_And_Mutability
Memahami sifat statis dan immutable Rust secara default.
- **CH-01_Immutability**: Mengapa default immutable dan penggunaan `mut`.
- **CH-02_Shadowing**: Teknik transformasi data tanpa mengubah mutabilitas.
- **CH-03_Constants**: Perbedaan antara `let` dan `const`.

### BK-02_Data_Types
Klasifikasi data yang dipahami oleh Rust.
- **CH-01_Scalar_Types**: Integer, Floating-point, Boolean, dan Char.
- **CH-02_Compound_Types**: Tuple dan Array (Statis & Fixed size).
