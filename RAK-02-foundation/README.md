# RAK-02-foundation (The Standard Book)

> **"Membangun Fondasi Sintaksis dan Logika Dasar Rust."**

Rak ini merupakan turunan langsung dari *The Rust Programming Language (The Book)*. Fokus pada pemahaman sintaksis dasar yang akan digunakan di seluruh modul tingkat lanjut.

## Fokus Pembelajaran
1. **Toolchain & Setup**: Berkenalan dengan `rustup`, `rustc`, dan `cargo`.
2. **Syntax Dasar**: Variabel, Mutabilitas, Tipe Data, dan Fungsi.
3. **Control Flow**: Kondisional dan Loop sistem.
