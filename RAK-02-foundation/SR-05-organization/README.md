# SR-05-organization (The Architect)

> **"Mengelola Proyek Skala Besar dengan Paket dan Modul."**

Sub-Rak ini mengajarkan sistem organisasi kode Rust agar tetap bersih dan terukur seiring berkembangnya kompleksitas proyek.

## 📚 Rencana Pengembangan (Books & Chapters)

### BK-01_Crates_Packages
Unit abstraksi tertinggi dalam ekosistem Rust.
- **CH-01_Bin_Lib_Crates**: Membedakan Crate biner dan library.
- **CH-02_Defining_Packages**: Struktur file `Cargo.toml` dan manajemen paket.

### BK-02_Modules_Paths
Mengatur hierarki kode internal.
- **CH-01_Mod_Hierarchy**: Mendefinisikan modul dalam satu file atau multi-file.
- **CH-02_Privacy_Pub**: Memahami visibilitas data dengan keyword `pub`.
- **CH-03_Use_Keyword**: membawa modul ke dalam scope dengan `use`.
