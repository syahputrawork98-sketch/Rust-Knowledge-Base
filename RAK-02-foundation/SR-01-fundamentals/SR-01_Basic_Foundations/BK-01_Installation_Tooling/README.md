# BK-01_Installation_Tooling

Buku ini memandu pembaca untuk menyiapkan lingkungan pengembangan Rust yang modern dan efisien.

## Daftar Bab (Chapters)
- **CH-01_Installing_Rust**: Setup `rustup` pada Windows, Linux, dan macOS.
- **CH-02_Troubleshooting**: Solusi error umum saat instalasi (Linker, PATH).
- **CH-03_Updates_Uninstall**: Mengatur siklus hidup toolchain.
- **CH-04_Local_Documentation**: Mengakses manual Rust secara offline.
- **CH-05_IDE_Tooling**: Konfigurasi VS Code, rust-analyzer, dan ekstensi pendukung.
