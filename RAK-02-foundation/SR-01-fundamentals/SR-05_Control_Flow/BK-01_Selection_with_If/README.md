# BK-01_Selection_with_If

> **"Persimpangan Jalan Logika."**

Memahami bagaimana Rust mengambil keputusan berdasarkan nilai boolean. Di Rust, `if` bukan sekadar perintah, tapi sebuah ekspresi yang bisa menghasilkan nilai.

## Daftar Isi
1. **CH-01_Basic_If_Expressions**: Pondasi pengambilan keputusan.
2. **CH-02_Else_If_Conditions**: Menangani skenario yang lebih kompleks.
3. **CH-03_If_in_let_Statements**: Keajaiban `if` sebagai penghasil nilai.
