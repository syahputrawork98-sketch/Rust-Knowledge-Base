# SR-03-logic-control (The Flow)

> **"Mengatur Alur Eksekusi dan Modularisasi Kode."**

Sub-Rak ini berfokus pada logika program. Bagaimana Rust membuat keputusan dan bagaimana kita membagi kode ke dalam unit-unit fungsional yang dapat digunakan kembali.

## 📚 Rencana Pengembangan (Books & Chapters)

### BK-01_Functions
Blok bangunan dasar dalam modularisasi Rust.
- **CH-01_Parameters**: Melewatkan data ke dalam fungsi.
- **CH-02_Statements_Expressions**: Memahami perbedaan krusial antara pernyataan dan ekspresi di Rust.
- **CH-03_Return_Values**: Mengembalikan data dari fungsi secara eksplisit maupun implicit.

### BK-02_Control_Flow
Logika kondisional dan pengulangan.
- **CH-01_Conditional_If**: Penggunaan `if` sebagai ekspresi.
- **CH-02_Looping**: Penggunaan `loop`, `while`, dan `for` untuk iterasi.
