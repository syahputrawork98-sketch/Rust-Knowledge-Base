# RAK-06-the-underworld (The Machine Room)

> **"Menembus Batas Keamanan: Unsafe Rust dan Interaksi Hardware."**

Rak ini membawa kita ke lapisan terdalam di mana aturan *Safe Rust* bisa dilanggar (dengan tanggung jawab penuh) demi performa atau interoperabilitas sistem.

## Fokus Pembelajaran
1. **Unsafe Rust**: Kontrak keamanan dan manipulasi *Raw Pointers*.
2. **FFI (Foreign Function Interface)**: Berkomunikasi dengan C/C++ dan memanggil ABI eksternal.
3. **Memory Layout**: Alignment, Padding, dan representasi fisik data di memori.
