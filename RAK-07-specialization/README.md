# RAK-07-specialization (The Cutting Edge)

> **"Penerapan Rust di Domain Spesifik Tingkat Tinggi."**

Setelah menguasai mekanika inti, Rak ini memfokuskan penggunaan Rust pada domain aplikasi modern seperti Web, Sistem Terdistribusi, dan Embedded.

## Fokus Pembelajaran
1. **WebAssembly (Wasm)**: Membawa performa sistem ke dalam Browser.
2. **Embedded Rust**: Menjalankan Rust di bare-metal hardware.
3. **High-Performance Async**: Arsitektur server skala besar.
