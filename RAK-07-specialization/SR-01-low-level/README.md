# SR-01-low-level (The Pulse)

> **"Optimasi dan Manipulasi Data Tingkat Instruksi."**

Sub-Rak ini mengeksplorasi penggunaan Rust untuk kontrol hardware dan optimasi tingkat rendah yang mendekati bahasa mesin.

## 📚 Rencana Pengembangan (Books & Chapters)

### BK-01_SIMD
*Single Instruction, Multiple Data* untuk performa ekstrem.
- **CH-01_Intrinsics**: Menggunakan instruksi khusus CPU.

### BK-02_Embedded_Fundamentals
Menjalankan Rust di bare-metal.
- **CH-01_No_Std_Environment**: Bekerja tanpa standard library.
- **CH-02_MMIO**: Memanipulasi port I/O memori secara langsung.
