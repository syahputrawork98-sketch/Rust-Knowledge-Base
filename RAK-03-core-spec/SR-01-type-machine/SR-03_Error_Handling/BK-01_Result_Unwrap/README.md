# BK-01_Result_Unwrap

> **"Antisipasi Kegagalan: Seni Berdamai dengan Error."**

Buku ini membahas filosofi penanganan error di Rust. Alih-alih menggunakan *exceptions*, Rust menggunakan Enum `Result` untuk memaksa pengembang menangani kemungkinan error sejak dini. Kita juga akan belajar kapan harus membiarkan program berhenti (*Panic*) dan kapan harus mencoba pulih dari kesalahan.

## Daftar Isi
1. **CH-01_The_Result_Enum**: Memahami varian `Ok` dan `Err`.
2. **CH-02_Panic_Vs_Errors**: Kapan harus menggunakan `panic!` vs penanganan error yang elegan.
