# BK-02_Trait_Objects

> **"Fleksibilitas Tanpa Batas: Polimorfisme di Runtime."**

Buku ini membahas **Trait Objects**, fitur Rust yang memungkinkan kita menggunakan polimorfisme sejati. Kita akan belajar bagaimana menyimpan berbagai tipe data yang berbeda di dalam satu koleksi yang sama, asalkan semuanya mengimplementasikan Trait yang ditentukan.

## Daftar Isi
1. **CH-01_Dyn_Traits**: Menggunakan `dyn` untuk fleksibilitas runtime.
