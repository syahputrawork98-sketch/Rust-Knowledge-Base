# BK-01_Trait_Bounds

> **"Syarat dan Ketentuan: Mengunci Kebebasan Generics."**

Buku ini membahas **Trait Bounds**, cara kita memberitahu Rust bahwa sebuah tipe data Generic tidak boleh "apa saja", melainkan harus memiliki kemampuan (Trait) tertentu. Ini adalah jembatan yang menghubungkan fleksibilitas Generics dengan kekuatan Traits.
