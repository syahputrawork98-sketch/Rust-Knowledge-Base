# SR-04_Advanced_Abstractions

> **"Batas dan Objek: Evolusi Sistem Tipe."**

Setelah memahami dasar-dasar Generics dan Traits, kita akan masuk ke teknik yang lebih dalam untuk mengikat tipe data dan mengelola polimorfisme saat dijalankan (Runtime).

## Daftar Buku
- **BK-01_Trait_Bounds**: Mengunci Generics dengan kontrak perilaku yang spesifik.
- **BK-02_Static_vs_Dynamic**: Memilih antara *Static Dispatch* dan *Dynamic Dispatch* (`dyn`).
