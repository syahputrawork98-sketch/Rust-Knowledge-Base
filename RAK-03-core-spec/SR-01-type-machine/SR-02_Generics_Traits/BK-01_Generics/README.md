# BK-01_Generics

> **"Templat Serbaguna: Satu Kode untuk Semua."**

Buku ini membahas **Generics**, kemampuan Rust untuk menulis fungsi atau tipe data yang bisa bekerja dengan berbagai jenis tipe lainnya tanpa harus menulis ulang kodenya. Generics adalah kunci efisiensi dan fleksibilitas dalam sistem tipe Rust.

## Daftar Isi
1. **CH-01_Type_Generics**: Menggunakan Generics pada Struct dan Enum.
2. **CH-02_Function_Generics**: Membuat fungsi yang bisa menerima berbagai tipe data.
