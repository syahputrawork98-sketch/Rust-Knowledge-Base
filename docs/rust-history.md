# Sejarah & Evolusi Rust

> **"Empowering Everyone to Build Reliable and Efficient Software."**

## 1. Proyek Personal (2006 - 2010)

Rust dimulai sebagai proyek sampingan oleh **Graydon Hoare** di Mozilla pada tahun 2006. Nama **Rust** diambil dari jamur karat (*rust fungus*) yang dikenal tangguh dan tersebar luas. Mozilla mulai mensponsori proyek ini secara resmi pada tahun 2009.

### Latar Belakang Masalah
Sebagai pengembang di Mozilla, Graydon melihat masalah sistemik pada browser Firefox yang dibangun dengan C++. Kesalahan manajemen memori (seperti *null pointer* atau *buffer overflow*) menyebabkan banyak celah keamanan dan *crash*. Rust diciptakan untuk menjadi bahasa sistem yang memiliki performa setara C++ namun dengan jaminan keamanan memori secara otomatis.

## 2. Kelahiran Komunitas & Versi 1.0 (2010 - 2015)

Rust diumumkan secara publik pada tahun 2010. Selama 5 tahun berikutnya, bahasa ini mengalami banyak perubahan radikal sebelum akhirnya mencapai stabilitas.
- **Versi 1.0 (Mei 2015)**: Menandai komitmen Rust terhadap stabilitas. Sejak saat itu, Rust menjamin bahwa kode yang valid hari ini akan tetap bisa dikompilasi di masa depan tanpa harus diubah total.

## 3. Era "Edition" (2018 - Sekarang)

Rust tidak merilis versi 2.0 yang memutus kompatibilitas. Sebagai gantinya, Rust menggunakan konsep **Edition** untuk memperkenalkan fitur besar secara bertahap.
- **Rust 2018 Edition**: Fokus pada produktivitas dan kemudahan penggunaan (ergonomics).
- **Rust 2021 Edition**: Fokus pada penyempurnaan fitur yang ada.
- **Rust 2024 Edition**: Membawa peningkatan performa dan fitur asinkron yang lebih matang.

## 4. Dominasi di Infrastruktur Modern

Selama bertahun-tahun, Rust terpilih sebagai "Most Loved Language" di survey Stack Overflow. Penggunaannya telah meluas ke perusahaan besar:
- **Big Tech**: AWS, Google, Microsoft, dan Meta kini menggunakan Rust untuk komponen kritikal di cloud dan sistem operasi.
- **Linux Kernel**: Rust menjadi bahasa kedua—setelah C—yang diizinkan masuk ke dalam kernel Linux, sebuah momen bersejarah dalam dunia sistem operasi.
