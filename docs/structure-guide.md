# Panduan Struktur & Standar (Structure Guide) - Rust Knowledge Base

Proyek **Rust Knowledge Base** disusun dengan analogi **Perpustakaan Digital** untuk merombak struktur dokumentasi teknis yang kaku menjadi unit pelajaran yang manusiawi.

Untuk menjaga konsistensi dan kemudahan kontrol, panduan ini membagi aturan penulisan menjadi beberapa modul standar:

## 🧭 Navigasi Standar

### 1. [Arsitektur & Hierarki](./standards/architecture.md)
Menjelaskan analogi Level 1-5 (Perpustakaan, Rak, Sub-Rak, Buku, Bab) serta kewajiban penempatan file penanda.

### 2. [Konvensi Penamaan & Struktur Folder](./standards/conventions.md)
Menentukan format folder (Prefix `RAK-`, `SR-`, `BK-`, `CH-`) dan struktur internal setiap Bab.

### 3. [Alur Kerja & Prosedur Penulisan (PPM)](./standards/workflow.md)
Detail tiga tahapan pengerjaan materi (Narasi, Kode, Visualisasi) serta penggunaan Mental Model Rust (seperti analogi Ownership).

### 4. [Protokol Pembaruan Status](./standards/status-protocol.md)
Aturan "Bottom-Up Aggregation" untuk memastikan akurasi data kemajuan dari level Bab ke level Rak.

## 📊 Status Keseluruhan
Kemajuan real-time proyek dapat dipantau di: **[Master Status Hub](../status.md)**.

---
> [!NOTE]  
> Semua penulisan aturan, kerangka, dan penataan menggunakan **Bahasa Indonesia** sebagai standar.
