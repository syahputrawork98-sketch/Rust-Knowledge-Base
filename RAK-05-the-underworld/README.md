# RAK-05-the-underworld (The Engine)

Rak ini membawa kita ke lapisan terdalam Rust, di mana aturan *Safe Rust* bisa dilanggar demi performa atau interaksi hardware.

## Fokus Pembelajaran
- **Unsafe Rust**: Kapan dan mengapa kita menggunakannya.
- **Raw Pointers**: Manipulasi memori langsung (`*const T`, `*mut T`).
- **FFI (Foreign Function Interface)**: Berbicara dengan C/C++.
- **Memory Layout**: Alignment, padding, dan representasi data fisik.

## 📊 Status Rak

## Sub-Rak (Sub-Racks)
- **SR-01_UnsafeRust**: Blok unsafe dan kontrak keamanannya.
- **SR-02_Interoperability**: FFI & ABI.
