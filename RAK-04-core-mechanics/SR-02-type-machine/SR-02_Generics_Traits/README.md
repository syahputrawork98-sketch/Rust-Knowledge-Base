# SR-02_Generics_Traits

> **"Templat dan Perilaku: Membangun Kontrak Kode."**

Sub-Rak ini memperkenalkan kekuatan abstraksi Rust. Kita akan belajar cara menulis kode yang bisa bekerja dengan berbagai tipe data (Generics) dan bagaimana mendefinisikan kemampuan atau perilaku yang bisa dimiliki oleh suatu tipe (Traits).

## Daftar Buku
- **BK-01_Generics**: Menghindari pengulangan kode dengan tipe generik.
- **BK-02_Traits_Basics**: Memahami *Shared Behavior* dan implementasi Trait.
