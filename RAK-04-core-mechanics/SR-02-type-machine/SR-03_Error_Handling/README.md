# SR-03_Error_Handling

> **"Ketenangan di Tengah Badai: Filosofi Error Rust."**

Rust tidak menggunakan *Exceptions*. Sebagai gantinya, ia menggunakan sistem tipe data yang memaksa kita untuk menangani kemungkinan kegagalan secara eksplisit. Sub-Rak ini membedah cara menulis program yang tangguh dan informatif saat terjadi error.

## Daftar Buku
- **BK-01_Result_Unwrap**: Mengenal `Result<T, E>` dan cara menangani hasil operasi.
- **BK-02_Propagation**: Menggunakan operator `?` untuk meneruskan error dengan elegan.
