# BK-02_Propagation

> **"Estafet Error: Meneruskan Tongkat Keputusan."**

Terkadang, sebuah fungsi tidak tahu cara menangani error yang terjadi di dalamnya. Alih-alih memaksakan solusi, fungsi tersebut bisa "meneruskan" error tersebut ke fungsi yang memanggilnya. Rust menyediakan operator `?` untuk melakukan hal ini dengan sangat ringkas.

## Daftar Isi
1. **CH-01_The_Question_Operator**: Menggunakan `?` untuk menulis kode yang bersih dari tumpukan `match`.
