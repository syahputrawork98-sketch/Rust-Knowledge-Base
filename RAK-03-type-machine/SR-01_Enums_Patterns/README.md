# SR-01_Enums_Patterns

> **"Klasifikasi dan Pencocokan: Seni Memilah Data."**

Sub-Rak ini membahas bagaimana Rust menangani data yang memiliki beberapa bentuk (Enums) dan bagaimana kita bisa memproses data tersebut secara elegan menggunakan Pattern Matching.

## Daftar Buku
- **BK-01_Enums_Option**: Fundamental Enums dan tipe favorit Rust: `Option`.
- **BK-02_Match_Control_Flow**: Menguasai `match`, `if let`, dan pola pencocokan tingkat lanjut.
