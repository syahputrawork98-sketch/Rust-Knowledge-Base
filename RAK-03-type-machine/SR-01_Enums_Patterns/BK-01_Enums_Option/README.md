# BK-01_Enums_Option

> **"Memetakan Kemungkinan: Hidup di Balik Pilihan."**

Buku ini membahas **Enums** (Enumerations), sebuah fitur powerful di Rust yang memungkinkan kita mendefinisikan tipe data dengan memilih satu dari beberapa varian yang mungkin. Kita juga akan mempelajari mengapa Rust tidak mengenal `null` dan bagaimana ia menggantinya dengan tipe `Option`.

## Daftar Isi
1. **CH-01_Basic_Enums**: Definisi dasar dan nilai konstanta.
2. **CH-02_Enums_With_Data**: Menyimpan informasi tambahan di dalam varian.
3. **CH-03_The_Option_Enum**: Menangani ketiadaan nilai tanpa takut `runtime error`.
