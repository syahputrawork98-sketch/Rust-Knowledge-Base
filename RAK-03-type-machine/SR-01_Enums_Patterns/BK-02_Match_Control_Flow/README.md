# BK-02_Match_Control_Flow

> **"Kendali Presisi: Membedah Setiap Kemungkinan."**

Setelah belajar bagaimana Enum membungkus berbagai kemungkinan data, sekarang kita akan belajar cara "membuka" bungkus tersebut dan mengeksekusi kode berdasarkan isinya. Rust menyediakan operator `match` yang sangat kuat dan sintaks `if let` yang ringkas untuk urusan ini.

## Daftar Isi
1. **CH-01_The_Match_Operator**: Mesin sortir data yang memastikan semua kasus ditangani.
2. **CH-02_If_Let_Syntax**: Cara cepat menangani satu varian spesifik secara elegan.
3. **CH-03_Pattern_Basics**: Memahami pola pencocokan (Patterns) di balik layar.
