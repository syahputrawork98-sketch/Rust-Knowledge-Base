# BK-02_Compound_Types

> **"Seni Mengelompokkan Informasi."**

Tipe Compound dapat mengelompokkan beberapa nilai menjadi satu tipe. Rust memiliki dua tipe compound primitif utama: tuple dan array.

## Daftar Isi
1. **CH-01_Tuple_Type**: Koleksi nilai dengan tipe berbeda.
2. **CH-02_Array_Type**: Koleksi nilai dengan tipe yang sama dan panjang tetap.
