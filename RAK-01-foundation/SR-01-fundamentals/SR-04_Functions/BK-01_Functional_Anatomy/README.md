# BK-01_Functional_Anatomy

> **"Bedah Saraf Logika Rust."**

Memahami struktur mendalam bagaimana sebuah fungsi bekerja, menerima informasi, dan memberikan hasil kembali kepada program utama.

## Daftar Isi
1. **CH-01_Syntax_and_Naming**: Definisi dan etika penamaan `fn`.
2. **CH-02_Parameters**: Jembatan data menuju fungsi.
3. **CH-03_Statements_vs_Expressions**: Rahasia di balik titik koma.
4. **CH-04_Return_Values**: Hasil akhir dari sebuah proses.
