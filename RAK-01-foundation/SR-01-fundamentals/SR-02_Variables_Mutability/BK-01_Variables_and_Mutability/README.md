# BK-01_Variables_and_Mutability

> **"Aturan Penamaan, Mutabilitas, dan Re-binding Data."**

Di Rust, variabel bukan sekadar wadah data. Ia adalah kontrak antara developer dan Compiler mengenai bagaimana data tersebut boleh diakses dan diubah. Buku ini membedah 4 pilar utama pengelolaan data dasar di Rust.

## Daftar Isi
1. **CH-01_Immutable_Default**: Filosofi "Sekali Tulis" (Analogi Segel Pabrik).
2. **CH-02_Mut_Keyword**: Membuka gerbang perubahan dengan `mut` (Analogi Izin Bongkar).
3. **CH-03_Constants**: Data abadi di tingkat program (Analogi Prasasti Batu).
4. **CH-04_Shadowing_Basics**: Konsep dasar Shadowing (Analogi Ganti Jubah).
5. **CH-05_Shadowing_Advanced**: Transformasi tipe data dan Scope Shadowing.
